
# Data Structures & Algorithms in Python

This repository tracks my core algorithm implementations, complexity analyses, and edge-case testing for Master's in CS/AI application portfolios.

---

### 📌 Topic 01: Searching Algorithms
* **`01_binary_search.py`** - Implemented $O(\log N)$ binary search algorithm in Python. Verified edge cases including empty arrays, single-element lists, and target present/missing scenarios.
* **`02_search_rotated_array.py`** - Modified binary search on pivoted sorted arrays with $O(\log N)$ time complexity.

### 📌 Topic 02: Binary Search Trees & Custom Data Structures
* **`03_user_database_classes.py`** - Class-based user database setup.
* **`04_bst_user_database.py`** - $O(\log N)$ Binary Search Tree implementation optimizing linear lookups.

### 📌 Topic 03: Arrays & Hashing
* **`05_two_sum.py`** - $O(N)$ hash map implementation to identify pair indices matching a target sum.
* **`06_valid_anagram.py`** - $O(N)$ character frequency mapping to determine valid string anagrams.
